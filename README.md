# Airport Weather — Android APK

Облачная сборка через GitHub Actions + Capacitor.

Локально не требуется Android Studio или Android SDK.

## Сборка

1. Создайте новый **публичный** или приватный GitHub repository.
2. Загрузите содержимое этой папки в repository.
3. Откройте вкладку **Actions**.
4. Запустите workflow **Build Android APK**.
5. После завершения откройте workflow run → **Artifacts** → `airport-weather-debug-apk`.
6. Скачайте APK и установите его на Android.
